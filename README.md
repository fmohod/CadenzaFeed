# Cadenza Arthouse

**Official Website:** https://cadenzaarthouse.com

> **Important:** This README provides a high-level overview of the project. The live website always takes precedence over repository documentation. Older planning documents may remain in the repository for historical reference and should not be considered current specifications.

Cadenza Arthouse is an independent media, journalism, photography, and creative commerce platform based in Houston, Texas.

The website is home to **Cadenza Arthouse Press**, featuring original reporting, event coverage, photography, interviews, community stories, artist features, and curated products from independent creators.

## Mission

Cadenza Arthouse documents culture, creativity, and community while providing artists, entrepreneurs, and organizations with a platform to share their work with a broader audience.

Our work combines:

- Journalism
- Photography
- Video production
- Editorial publishing
- Community event coverage
- Artist and business features
- Curated marketplace partnerships

## Project Structure

The website currently includes:

- Cadenza Arthouse Press
- About
- Get Featured
- Support / Membership
- Marketplace
- Community Resources
- Media Library
