# Epoch

An **original homage** to classic 16-bit JRPG menu interfaces — gilded window
frames, oxblood panels, and cream text on aged leather. Built for CAIN OS.

- **Layout profile:** `terminal-classic`
- **Animation profile:** `fade`
- **Sound profile:** `terminal-basic` (CAIN OS synthesizes these; no audio files ship)
- **CRT:** off — Epoch presents a clean SNES-console look (no scanlines/glow)

## Legal note

This pack is an **inspired-by original**. All artwork (`skin.css`, `preview.svg`,
`assets/parchment.svg`) is authored in-house. It contains **no** ripped sprites,
frame art, or fonts from any commercial game. Lettering uses the open-licensed
**Pixelify Sans** font loaded by CAIN OS.

## What it provides

Presentation only, per the CAIN Interface Pack Specification v1.0:

- `skin.css` — sets the CAIN OS core CSS variables and skins the window frames,
  menu rows, headings, and settings cards
- `assets/parchment.svg` — the tiled leather backdrop
- `preview.svg` — the Display Settings card image

No JavaScript, no HTML, no network requests. CAIN OS owns all behavior.
